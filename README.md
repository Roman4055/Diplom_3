## Описание

Проект покрывает семь ключевых пользовательских сценариев сервиса Stellar Burgers:

1. Переход в «Конструктор» по кнопке в шапке.
2. Переход в «Ленту заказов» по кнопке в шапке.
3. Открытие модального окна с деталями ингредиента.
4. Закрытие модального окна крестиком.
5. Увеличение счётчика ингредиента при добавлении в заказ.
6. Рост счётчиков «Выполнено за всё время» и «Выполнено за сегодня» в ленте после оформления заказа.
7. Появление номера нового заказа в ленте заказов.

Каждый сценарий выполняется в двух браузерах — Chrome и Firefox (параметризованная фикстура).

Полный прогон (Chrome + Firefox):

pytest -v --alluredir=./allure-results

Headless-режим (без открытия окон браузера):

pytest -v --headless --alluredir=./allure-results

Один браузер:

bash

Один сценарий (например, сценарий 7):

Allure-отчёт
После прогона сформировать и открыть отчёт:

bash
allure serve ./allure-results
Отчёт содержит шаги каждого теста (через декораторы @allure.title / @allure.feature), статус по браузерам и историю запусков при повторных прогонах.

Особенности реализации
Устойчивые ожидания. Все действия с элементами идут через явные ожидания (WebDriverWait) в BasePage; поиск карточек ингредиентов дублируется поллингом — SPA отрисовывает список не мгновенно.
Drag-and-drop. Реализован двумя способами: основной — цепочка ActionChains (click_and_hold → move_to_element → release), запасной — эмуляция HTML5-событий через execute_script. Запасной способ страхует Firefox, где нативный drag-and-drop работает нестабильно.
Модальные окна. Закрытие идёт по трём стратегиям: крестик → первая кнопка в модалке → Escape. Окно считается закрытым после исчезновения контейнера из DOM, а не по паузе.
Заглушка номера заказа. Стенд показывает номер не сразу: сначала в модалке пустая строка или 9999. Метод get_created_order_number опрашивает окно до появления реального номера и нормализует ведущие нули (04988 → 4988).
Мгновенное выполнение заказов. На стенде новый заказ может миновать секцию «В работе» и сразу оказаться в «Готовы», поэтому проверка сценария 7 ищет номер во всём блоке статусов, а не только в одной секции.
Кроссбраузерность. Фикстура driver параметризована — каждый тест автоматически запускается в Chrome и Firefox.
